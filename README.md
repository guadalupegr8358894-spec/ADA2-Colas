# ADA2 - Colas (Unidad 3: Estructuras Lineales)

Repositorio para la actividad ADA2 de la materia, centrado en la implementación y uso de la estructura de datos Cola (Queue) en Python[cite: 1, 3, 4, 5].

## 📂 Archivos incluidos

* **`suma.py`**: Función que recibe dos colas con números enteros y devuelve una nueva cola con sus elementos sumados uno a uno[cite: 3, 5]. Incluye pruebas con los datos de ejemplo solicitados[cite: 5].
* **`sistema.py`**: Aplicación de consola para la gestión de colas de servicio de una compañía de seguros[cite: 3, 4]. Permite simular la llegada (`C`) y la atención (`A`) de clientes por número de servicio[cite: 3, 4].

## 🚀 Cómo ejecutar los programas

Asegúrate de tener Python instalado[cite: 3]. Puedes correr cada programa desde tu terminal con los siguientes comandos:

* Para ejecutar la suma de colas:
  ```bash
  python suma.py
